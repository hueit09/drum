公開前の検証一式。

    python3 tools/build.py        # 版の印を打つ
    tools/test/check.sh           # 全検証（Node と Playwright が要る）

構文・レシピ再現・画面の崩れ・通し操作・マイクで読む・曲から、の6本。
1つでも落ちたら公開しない。

`song.js` は `tools/test/fix/` の音源（ドラムだけ・バンド入り・実際の曲の断片）を使う。
他人の録音を含むのでリポジトリには置いていない。無いときは「曲から」の検証だけ飛ばす。
`audit.js` は全キー×全プリセットのレシピ検算（実音が音階に乗っているか、表裏の音程、実用レンジ）。
